# Лабораторні роботи

Цей репозиторій призначений для здачі лабораторних робіт студентами, включно зі звітами та програмним кодом.

Кожен студент повинен додавати свої роботи до **власної папки** та надсилати зміни через **Pull Request (PR)** до гілки `main` цього репозиторію.

## Структура репозиторію

Для кожного студента використовується окрема папка з його прізвищем:

```text
/
├── Прізвище1/
│   ├── Lab1/
│   │   ├── report.pdf
│   │   └── code.c
│   ├── Lab2/
│   │   ├── report.pdf
│   │   └── code.c
│   └── Lab3/
│       ├── report.pdf
│       └── code.c
│
├── Прізвище2/
│   ├── Lab1/
│   │   ├── report.pdf
│   │   └── code.c
│   └── Lab2/
│       ├── report.pdf
│       └── code.c
│
└── README.md
```

### Вимоги до структури

1. Кожен студент має **власну папку**, названу його прізвищем.
2. **Кожна лабораторна робота повинна знаходитися в окремій папці** всередині папки студента.
3. Звіт повинен бути у форматі **PDF**.
4. Програмний код повинен бути розміщений **в окремих файлах**.
5. Звіт і код повинні знаходитися в папці відповідної лабораторної роботи.
6. Не можна змінювати або видаляти файли інших студентів.

Наприклад:

```text
Прізвище/
└── Lab1/
    ├── report.pdf
    └── solution.c
```

# Як здати лабораторну роботу

## 1. Створіть Fork репозиторію

Відкрийте цей репозиторій на GitHub та натисніть **Fork**.

У результаті у вашому GitHub-акаунті буде створена власна копія репозиторію.

> Працювати потрібно у своєму **Fork**, а не безпосередньо в оригінальному репозиторії.

---

## 2. Клонуйте свій Fork

## 3. Створіть свою папку

У корені репозиторію створіть папку зі своїм прізвищем.

Наприклад:

```text
Ivanenko/
```

Якщо ваша папка вже існує, використовуйте її.

---

## 4. Створіть папку лабораторної роботи

Для кожної лабораторної роботи створюйте **окрему папку**.

Наприклад, для лабораторної роботи №1:

```text
Ivanenko/
└── Lab1/
```

Для лабораторної роботи №2:

```text
Ivanenko/
├── Lab1/
└── Lab2/
```

---

## 5. Додайте звіт та код

У папку лабораторної роботи додайте:

- звіт у форматі **PDF**;
- програмний код в **окремому файлі**.

Наприклад:

```text
Ivanenko/
└── Lab1/
    ├── report.pdf
    └── solution.c
```

Якщо лабораторна робота містить декілька файлів із кодом, їх можна розмістити в тій самій папці:

```text
Ivanenko/
└── Lab1/
    ├── report.pdf
    ├── task1.c
    ├── task2.c
    └── task3.c
```

---

## 6. Зробіть Commit

## 7. Завантажте зміни у свій Fork

Виконайте:

```bash
git push
```

Після цього ваші зміни будуть доступні у вашому Fork на GitHub.

# Як створити Pull Request

Після завантаження змін відкрийте свій Fork на GitHub.

GitHub зазвичай покаже кнопку:

**Compare & pull request**

Натисніть її.

Якщо кнопка не відображається:

1. Відкрийте вкладку **Pull requests**.
2. Натисніть **New pull request**.
3. Виберіть свій Fork як джерело змін.
4. Виберіть **оригінальний репозиторій** як репозиторій призначення.
5. Як цільову гілку виберіть **`main`**.

### Напрямок Pull Request

Pull Request повинен мати такий напрямок:

```text
Ваш Fork
    │
    │ Pull Request
    ▼
Оригінальний репозиторій → main
```

Тобто ви надсилаєте зміни **зі свого Fork у `main` оригінального репозиторію**.

---

# Важливо

У Pull Request повинні бути зміни **лише у вашій папці**.

Наприклад, якщо ваше прізвище `Ivanenko`, правильний PR виглядає так:

```text
Ivanenko/
└── Lab1/
    ├── report.pdf
    └── solution.c
```

Не можна додавати або змінювати файли в папках інших студентів.

### Правильно

```text
Ivanenko/
└── Lab1/
    ├── report.pdf
    └── solution.c
```

### Неправильно

```text
Lab1/
├── report.pdf
└── solution.c
```

Лабораторна робота повинна знаходитися всередині вашої папки.

### Неправильно

```text
Ivanenko/
├── report.pdf
├── Task1.c
└── Task2.c
```

Кожна лабораторна робота повинна мати власну папку.

### Неправильно

```text
Ivanenko/
└── Lab1/
    └── report.docx
```

Звіт повинен бути у форматі PDF.

---

# Перевірка перед створенням Pull Request

Перед створенням PR переконайтеся, що:

- [ ] ваша папка названа вашим прізвищем;
- [ ] кожна лабораторна робота знаходиться в окремій папці;
- [ ] звіт має формат PDF;
- [ ] код знаходиться в окремому файлі;
- [ ] усі ваші файли знаходяться всередині вашої папки;
- [ ] ви не змінювали файли інших студентів;
- [ ] Pull Request направлений до `main` оригінального репозиторію.

## Коротко

```text
Fork
  ↓
Clone
  ↓
Створити/відкрити свою папку
  ↓
Створити папку LabX
  ↓
Додати PDF + код
  ↓
Commit
  ↓
Push
  ↓
Pull Request → main
```

**Усі лабораторні роботи здаються через Pull Request до `main` оригінального репозиторію.**
